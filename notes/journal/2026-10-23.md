## Learned
- Assignment (build + push to Docker Hub) needs **no** self-hosted runner \u2014 GitHub-hosted runner talks to Docker Hub cloud-to-cloud. Self-hosted only for deploying onto our private server (outbound polling).
- Fork PRs run *their* workflow file \u2192 `runs-on` in our files isn't a lock; approval is.
- Image vs container; container port vs host port (many containers can use 8000 inside; host port must be unique).
- Two `/health` log lines: `127.0.0.1` (HEALTHCHECK inside) vs `172.17.0.1` (our curl via Docker bridge) \u2192 why 0.0.0.0 inside containers.
- Our code is 74 kB of a 361 MB dependency layer \u2192 layer order = fast rebuilds/pushes.
