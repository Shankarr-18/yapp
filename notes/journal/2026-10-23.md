- Tried releasing `0.1.1` → validate failed ("!= __version__ 0.1.0"), everything else skipped.

## Learned
- Reusable workflow = function: inputs = parameters, outputs = return value. Only reusable workflows have workflow-level outputs.
- Pass secrets explicitly, not `secrets: inherit` (least privilege).
- A job that calls a reusable workflow can't have `environment:` → separate gate job.
- Never put `${{ inputs.x }}` directly in `run:` (script injection) — pass via `env:`.
- Release rebuild → different digest than CI's `sha-f3cd704` for the same commit → "build once, promote" is better (Lesson 7).
- `ubuntu-latest` is a moving label (migrating to Ubuntu 26) → pin `ubuntu-24.04`.
