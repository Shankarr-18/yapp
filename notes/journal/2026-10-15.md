# Lesson 1: App

## Did
- Built **yapp — Personal Finance Toolkit**: EMI, SIP, Budget analyzer.
- FastAPI REST API + Gradio UI mounted at `/ui`, single uvicorn process on port 8000.
- Env-based config with fail-fast validation, stdout logging, `FinanceError` → HTTP 400 / UI popup, `/health`.
- Smoke-tested every endpoint with `Invoke-RestMethod` (incl. 0% EMI edge case and a 400 error).

## Learned
- Separation of concerns: `core/` has no framework imports.
- ASGI server (uvicorn) vs framework (FastAPI); auto docs at `/docs`.
- 400 vs 422 vs 500.
- Libraries can phone home (Gradio telemetry) — disable in production.

## Decisions
- App: Personal Finance Toolkit (better for resume than a plain budget app; calculators become agent tools in Phase 7).
- UI: Gradio over Streamlit (mounts inside FastAPI, ML/agent friendly). See [app-architecture](../concepts/app-architecture.md).
- Branching: only `main` for now; `dev` + PR flow later.
