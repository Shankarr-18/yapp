## Learned
- Collection error (`E`, nothing ran, exit 2) vs test failure (`F`).
- Expected values must come from an independent oracle (textbook value, closed-form formula), not the same formula.
- Boundary tests catch off-by-one; tests that never failed are unproven.
- `monkeypatch` for env vars; beware `lru_cache` in tests.
- pytest's "in Xs" can miss startup work: conftests under CLI path args load before the session timer (`pytest tests/integration` said 0.07s, wall 2.7s). Use `time pytest` for real timings. Unit ≈ 0.35s, integration ≈ 2.7s (Gradio import).
- Coverage finds gaps; it doesn't prove correctness.
