- Rollback drill: `deploy` shell function; 0.1.1 → 0.1.0 in 4.8 s → back to 0.1.1.

## Learned
- Long polling: runner keeps an outbound request open; GitHub answers when there's a job.
- Checksum = fingerprint of a download (same idea as an image digest). Scan pasted output for secrets; leading space keeps a command out of history (`HISTCONTROL=ignoreboth`).
- 5xx = provider's fault; check the status page; keep a manual runbook.
- `localhost` = "the machine I'm on". A tunnel (VS Code / `ssh -L`) lets my localhost reach the server's localhost.
- Log `127.0.0.1` = health check inside the container; `172.17.0.1` = traffic coming in through Docker from outside.
- Rollback is seconds because versions are immutable boxes on the shelf. The `Connection reset` lines during deploy = a few seconds of downtime (zero-downtime: blue-green/rolling, Phase 3).
