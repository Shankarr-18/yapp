## Learned
- Release = promote the tested artifact, not rebuild it. Tested digest == shipped digest.
- Releases must run on a commit CI built (notes-only commits have no `sha-` image).
- Tests should read values from the single source of truth (`__version__`), not hardcode them.
- Terminal traps: `git diff` opens the pager `less` → press **q** (keys are less commands; Ctrl+Z only suspends → `jobs`, `kill %1`). Unexpected `>` prompt = unclosed quote → Ctrl+C.
- Predicted "2 digests" — wrong: CI's `main`/`sha-` and the release tags are now on the same box.
